# 编译指导

## 环境要求

- **.NET SDK 10.0** 或更高版本
- **Visual Studio**（可选，用于 IDE 开发）

## SDK 安装位置

SDK 安装在用户目录下：

```
C:\Users\admin\.dotnet\sdk\10.0.403
```

## 编译命令

### 方式一：使用完整路径编译

```powershell
& "C:\Users\admin\.dotnet\dotnet.exe" build SmartHdrManager.csproj -c Release
```

### 方式二：添加用户级 PATH 后编译

在 PowerShell 中执行：

```powershell
$env:PATH = "C:\Users\admin\.dotnet;" + $env:PATH
dotnet build SmartHdrManager.csproj -c Release
```

### 方式三：永久添加用户级 PATH

1. 打开 **系统属性** → **高级** → **环境变量**
2. 在 **用户变量** 中找到 `Path`，点击 **编辑**
3. 添加：`C:\Users\admin\.dotnet`
4. 重新打开 PowerShell，即可直接使用 `dotnet` 命令

## 编译配置

- **仅允许 Release 配置**
- **禁止 Debug 配置**

```powershell
# 正确 ✅
dotnet build SmartHdrManager.csproj -c Release

# 错误 ❌
dotnet build SmartHdrManager.csproj -c Debug
```

## 清理构建产物

```powershell
dotnet clean SmartHdrManager.csproj
```

## 输出位置

- **DLL**：`bin\Release\net10.0-windows\SmartHdrManager.dll`
- **EXE**：`bin\Release\net10.0-windows\SmartHdrManager.exe`

## 目标框架

- `net10.0-windows`
- 平台：`x64`（默认）/ `win-arm64`（ARM64 设备）

## 警告处理

编译时如出现警告，应及时修复。常见警告类型：

| 警告码 | 说明 | 处理方式 |
|--------|------|----------|
| CS0472 | `bool` 与 `bool?` 比较 | 移除 `!= null` 判断 |
| CS0414 | 字段已赋值但从未使用 | 删除未使用字段 |
| CS0649 | 字段从未赋值 | 补充赋值或移除字段 |
